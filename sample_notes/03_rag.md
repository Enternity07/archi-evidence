# RAG 检索增强生成

这是软件项目的原创教学说明，不是性能研究结论。

## RAG 流程
RAG 将文档解析、文本分块、检索和生成串联起来。首先给片段保存来源路径与行号，再检索相关片段，将其作为上下文交给语言模型。没有检索到证据时应说明知识不足。

## BM25 与向量检索
BM25 根据词项频率与文档长度计算词法相关性。向量检索使用嵌入模型表示语义。BM25 不等同于 embedding；当前项目只实现 SQLite FTS5 的 BM25，没有向量库与重排器。

## 引用核验
检查引用编号存在，仅能排除部分编造来源的情况，不能证明回答得到来源支持。语义一致性仍要人工抽查或设计独立评测。
