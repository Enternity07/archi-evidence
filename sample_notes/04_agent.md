# Agent 与工具调用

## Agent Loop
一个基础 Agent Loop 包含模型提出工具调用、程序校验参数、执行工具、把结果回传模型以及终止。模型只能提出调用，实际执行与权限边界由程序控制。应限制总轮次、单轮调用次数和参数长度。

## 工具白名单
工具白名单只暴露允许的操作。本项目提供 search_notes 和 calculate，不提供 Shell、任意 Python 执行或文件写入。算式经 AST 校验，仅允许数字、括号和加减乘除。

## 提示注入
提示注入可能把恶意指令藏在检索文档中。系统提示与工具权限可以降低部分风险，但无法保证语言模型不受影响。工具返回的文本应被视为数据，不得扩大执行权限。
